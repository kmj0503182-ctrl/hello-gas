# 실습 프로젝트

## 목적
이 폴더는 가상 데이터로 작은 결과물을 만들고, AI와 함께 작업하는 과정을 연습하는 프로젝트입니다.

- 프로젝트 경로: `C:\AI-Class\hello-gas`
- 목표: **미정 — [만들고 싶은 작은 결과물]을 구체적인 내용으로 바꿔 주세요.**
- 현재 상태: 프로젝트 안내와 AI 작업 규칙 초안만 작성한 단계입니다.
- 완료 기준: 목표를 확정한 뒤, 필요한 최소 기능과 로컬에서 결과를 확인할 방법을 정합니다.

## 파일 안내
- `README.md`: 프로젝트 목적, 준비 사항, 진행 방법
- `AGENTS.md`: 이 폴더에서 AI가 지켜야 할 작업 규칙

## 데이터와 작업 범위
- 실제 개인정보 대신 직접 만든 가상 데이터만 사용합니다.
- 예시: 사용자 `demo-user-001`, 이메일 `demo@example.com`, 가상 점수 `85`.
- 비밀번호, API 키, 인증 토큰 등 비밀정보를 문서나 코드에 넣지 않습니다.
- 파일 삭제, 외부 업로드, 배포는 실행하지 않습니다.

## 필요한 설정
현재 문서 작성 단계에는 추가 설치나 계정 연결이 필요하지 않습니다. 사용할 언어, 실행 도구, 패키지, 인증 설정은 목표가 정해진 뒤 필요한 것만 선택합니다. 실행 명령은 아직 없습니다.

## 직접 할 일
1. 이 폴더를 사용할 프로젝트 경로로 확정합니다.
2. 만들고 싶은 결과물을 한 문장으로 적습니다. 예: “가상 지출 내역을 합산하는 작은 도구”.
3. 꼭 필요한 기능 1~3개와 원하는 결과 형태(웹 화면, 파일, 명령줄 등)를 정합니다.
4. 목표 확정 후 이 문서에 실행 방법과 확인 절차를 추가합니다.
